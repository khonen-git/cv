# Brainstorm CV — 8 versions (A / B / C / Hybride × 1p / 2p)

Objectif commun à toutes les versions :
- Cible : **alternance Data Scientist ML (18 mois)** uniquement
- Skills = mots-clés (pas de détail)
- Projets = preuves des skills (titres RH-explicites)
- Soft skills visibles et « RH-friendly »
- Peu de bullets, maximum de chiffres
- Research = projets

Légende densité projets :
- **L1** = flagship (titre + 1–2 bullets chiffrés)
- **L2** = titre + 1 ligne / 1 bullet
- **L3** = titre seul (explicite)
