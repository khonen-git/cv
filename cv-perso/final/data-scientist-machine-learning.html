Projets

Laboratoire ML — Séries temporelles haute fréquence

Python · scikit-learn · XGBoost · PyTorch · Dagster · MLflow

Plateforme Python modulaire de recherche ML sur séries temporelles exigeantes, couvrant le cycle complet ingestion → features → labels → modèles → évaluation → déploiement.

  • Traitement de plusieurs dizaines de millions d’observations
  • Construction configurable via Hydra de features, labels multi-horizons et datasets prêts pour la modélisation.
  • Architecture modulaire ; pipelines reproductibles Dagster avec suivi des paramètres, métriques et artefacts dans MLflow.
  • ~950 tests automatisés et validation temporelle robuste : OOS, walk-forward, purging et contrôles de falsification.
  • Accélération du fit modèles (RF jusqu’à ≈ 40× vs 1 cœur ; XGBoost ≈ 2,9×).
  • Déploiement sur VPS : API d’inférence FastAPI et démo live du pipeline.
  • UI centralisée Streamlit : dashboards, rapport d'expériences, visuels graphiques dynamiques

Recherche ML — Régimes et prédictibilité des séries temporelles

HMM · XGBoost · event conditioning · validation OOS

Étude de la détection, de la persistance et de la prédictibilité de régimes dans des séries temporelles.

  • Comparaison de modèles supervisés et HMM sous validation temporelle hors échantillon.
  • Signal mesurable sur certains labels de régime (ROC-AUC ≈ 0,70–0,80).
  • Analyse des transitions d’états, de leur persistance et de la durée de vie de l’information.

Détection de faux billets

Classification · QDA · XGBoost

Classification sur 1 500 billets (6 caractéristiques géométriques) pour détecter les contrefaçons.

  • Imputation des NA, comparaison de plusieurs classifieurs (logistique, RF, XGBoost, QDA…).
  • ≈ 99 % d’accuracy ; seuils via matrices de confusion ; QDA packagé (joblib) pour l’inférence.

Segmentation pays pour priorisation d’export

PCA · clustering

Segmentation de 125 pays pour identifier des marchés d’export prioritaires.

  • PCA + clustering K-means/CAH sur 10+ indicateurs ; 4 composantes ≈ 78 % de variance.
  • Clusters à fort potentiel d’import vs peu prioritaires — restitution orientée décision.
